Average profile by group

Each of the six groups has a characteristic shape. This table is the plain version of it: for every one of the fourteen sub-scores, the mean across the minerals in a group. The highest value in each row is highlighted in that group's colour, so you can read across a row to see which group leads on a given dimension.

Hover a column to spotlight one group. The numbers are means, so they can sit between the 1–5 / 1–10 band scores. They are never summed.
